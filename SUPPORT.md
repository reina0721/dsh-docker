# Support

- Read [docs/troubleshooting.md](docs/troubleshooting.md) and
  [docs/faq.md](docs/faq.md) first.
- Run `dshctl doctor --network` and include the output in bug reports.
- Use GitHub Issues for reproducible bugs and feature requests.
- Use GitHub private security advisories for vulnerabilities.

This is a community project; there is no guaranteed response time or commercial
support.
